# Doodle Icons for Vue 3

[![npm version](https://img.shields.io/npm/v/@doodle-icons/vue)](https://www.npmjs.com/package/@doodle-icons/vue)

400+ handcrafted doodle icons. Based on icon designs by [Khushmeen Sidhu](https://khushmeen.com/icons.html).

[Browse all icons →](https://thejian.github.io/doodle-icons/)

## Installation

```bash
npm install @doodle-icons/vue
```

## Usage

```vue
<script setup>
import { Rocket } from '@doodle-icons/vue';
</script>

<template>
  <Rocket :size="64" color="hotpink" />
</template>
```

Use `size` and `color` to customize an icon.
