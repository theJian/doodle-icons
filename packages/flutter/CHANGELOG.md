# 0.2.0

- Set an icon's width and height together with `size`, for example `const Rocket(size: 48)`. Use `width` and `height` to override either dimension independently.
- **Breaking:** Icons now default to 24 × 24 logical pixels instead of their SVG's intrinsic dimensions. If your layout relied on the previous default, set `size` or explicit `width` and `height` values.
